# 🛍️ StoreMate

**StoreMate** — это полнофункциональное приложение для администрирования магазина. Оно включает:

- 📦 Веб-интерфейс для управления базой данных товаров и заказов
    
- 🖥️ Десктопное приложение WinForms (.NET 8.0)
    
- 🗄️ Серверную часть на Flask + PostgreSQL, развёрнутую через Docker
    

Проект идеально подойдёт для малого бизнеса или учебных целей, где нужно быстро развернуть систему учёта.

---

## 🚀 Основные возможности

- Управление товарами, категориями и остатками
    
- Обработка заказов
    
- API для интеграции
    
- Простая и быстрая установка с Docker
    
- Кроссплатформенный веб-интерфейс
    
- Десктопный клиент под Windows
    

---

## 🛠️ Используемые технологии

|Компонент|Технология|
|---|---|
|Backend|Python 3.11, Flask|
|База данных|PostgreSQL|
|Веб-интерфейс|HTML, JavaScript (Vanilla)|
|Десктоп клиент|WinForms (.NET 8.0, C#)|
|Контейнеризация|Docker, Docker Compose|

## ⚙️ Установка и запуск

### 1. 📥 Клонируйте репозиторий

bash

КопироватьРедактировать

`git clone https://github.com/viffky/STORE-MATE.git cd STORE-MATE`

### 2. 🐳 Запустите через Docker

Убедитесь, что Docker и Docker Compose установлены и запущены.

bash

КопироватьРедактировать

`docker-compose up --build`

> При первом запуске произойдёт сборка контейнеров и инициализация базы данных.
